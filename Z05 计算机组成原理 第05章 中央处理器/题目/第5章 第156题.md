# 第5章 第156题

<div class="wd-head"><span class="wd-badge">计算机组成原理 · 第05章 · 156</span><span class="wd-chip qtype-选择">选择题</span><span class="wd-chip">5.7 多处理器的基本概念</span><span class="wd-chip">指令与 CPU</span></div>

> [!question] 题干
> 下列关于超线程（HT）技术的描述中，正确是（）。

<div class="wd-opts">
<div class="wd-opt"><b>A</b><span>超线程技术可以让四核 Intel Core i7 处理器变成八核</span></div>
<div class="wd-opt"><b>B</b><span>超线程技术是一项硬件技术，能使系统性能大幅提升，与操作系统和应用软件无关</span></div>
<div class="wd-opt"><b>C</b><span>含有超线程技术的CPU 需要芯片组支持才能发挥技术优势</span></div>
<div class="wd-opt"><b>D</b><span>超线程技术模拟出每个CPU 核都具有独立资源，各自工作互不干扰</span></div>
</div>

> [!success] 答案
> **C**

## 解析要点

<div class="wd-expl">

超线程技术是在一个 CPU 中，提供两套线程处理单元，让单个处理器实现线程级并行。虽然采用超线程技术能够同时执行两个线程，但是当两个线程同时需要某个资源时，其中一个线程必须暂时挂起，直到这些资源空闲后才能继续运行。因此，超线程的性能并不等于两个 CPU 性能。而且，超线程技术的 CPU 需要芯片组、操作系统（如 Windows 98 不支持超线程技术）和应用软件的支持，才能发挥该项技术的优势。双核技术是指将两个一样的 CPU 集成到一个封装内（或者直接将两个 CPU 做成一个心片），而超线程技术在 CPU 内部仅复制必要线程资源来让两个线程同时运行，能并行执行两个线程，模拟实体双核。仅选项C正确。

</div>
