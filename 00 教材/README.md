# 教材 PDF 怎么来

这个库只版本化**笔记、题目、导图、canvas**，不含教材 PDF —— 单本 200–300 MB，超过 GitHub 单文件 100 MB 上限。

教材与思维导图放在本仓库的 Release 里：

**https://github.com/2486809961-alt/wangdao-408/releases/tag/textbooks-2027**

## 新电脑上一键还原

```bash
git clone https://github.com/2486809961-alt/wangdao-408.git
cd wangdao-408
bash "99 脚本/restore-textbooks.sh"
```

脚本会按 `99 脚本/textbooks-manifest.json` 把 9 个 PDF 放回原位，逐个校验 sha256，已存在且校验通过的直接跳过，失败重跑可续传。

## 两点说明

- **没做二次压缩**：PDF 内部已是 deflate 压缩流，实测 `zstd -3` 对 224 MB 的《操作系统》反而涨到 231.9 MB。所以直接原样上传，字节与本地一致，sha256 能对上。
- **坚果云同步请排除 PDF**：否则每次同步要传 1 GB。在 Nutstore Sync 的过滤规则里加 `*.pdf`。
