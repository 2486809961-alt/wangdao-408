> [!question] 题干
> 假定变量i是一个32 位 int型整数，f和d分别为 float型（32位）和 double型（64
> 位）实数。分析下列各布尔表达式，说明结果是否在任何情况下都是 “true”。
> 1） i== （int） （（double）i）
> 2） f==（float） （（int） f）
> 3） f= （float） （（double） f）
> 4） d== （double） （（float） α）

## 解析要点

<div class="wd-expl">

强制类型转换，转换过程有两个，一是 unsigned int-int→long→double，二是 float--double，从后向前转换会使得数据丢失，进而使等号不成立。

1）是。因为 double 型比 int 型精度高，所以 int 型变量转换为 double 型变量时不会有精度损失。

2）不是。因为 float 型有小数部分，而 int 型没有小数部分，所以把 float 型变量转换为 int型变量时，可能丢失小数部分。

3） 是。因为 double型比 float 型精度高，所以 float 型变量转换为 double 型变量时不会有精度损失。

4）不是。因为 float型比 double 型的有效位数少，所以 double 型变量转换为 float 型变量时会有精度损失。

</div>
