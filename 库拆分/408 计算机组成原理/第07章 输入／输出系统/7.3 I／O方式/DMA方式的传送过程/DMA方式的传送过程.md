## 三、知识点要点（摘自本书解析）

- **第7章 第11题**：当 CPU与 DMA 控制器同时访问主存时，DMA 请求通常具有更高的优先级，以确保高速外设数据及时传输，避免丢失；因此，在总线仲裁层面，DMA 的优先级高于普通中断请求，说法1正确。程序中断方式需要切换 CPU 执行流程，必须保存和恢复现场：而 DMA 由专用硬件直接完成数据传送，不经过 CPU，不使用其寄存器，因此无须保存现场一一正如唐朔飞所编教材《计算机组成原理》中所述：“DMA 方式无须保
- **第7章 第27题**：、D在程序查询方式中，CPU 与外设串行工作，传送与主程序串行工作。在中断万式中，CPU与外设并行工作，当数据准备好时仍需中断主程序以执行数据传送，因此传送与主程序仍是串行的。在DMA方式中，CPU 与外设、传送与主程序都是并行的。
- **第7章 第36题**：DMA 传送数据时，挪用周期不会改变CPU 现场，因此无须占用 CPU钓PC和寄存器。
- **第7章 第37题**：DMA 方式的数据传送不经过 CPU，但需要经过 DMA 控制器中的数据缓冲寄存器。输入时，数据由外设（如磁盘）先送往DMA 数据缓冲寄存器，再通过数据总线送到主存。反之，输出时，数据由主存通过数据总线送到DMA 数据缓冲寄存器，然后送到外设。
- **第7章 第46题**：中断1/O方式：在I/O 设备输入每个数据的过程中，由于无须 CPU 干预，因此可使 CPU 与I/O 设备并行工作。仅当输完一个数据时，才需要 CPU 花费极短的时间去做一些中断处理。因此中断申请使用是 CPU 处理时间，发生时间是在一条指令执行结束之后，数据在软件的控制下完成传送。而 DMA方式与之不同。DMA 方式：数据传输的基本单位是数据块，即在 CPU 与1O设备之间，每次传送至少一个数
- **第7章 第54题**：周期挪用法由 DMA 控制器挪用一个或几个主存周期来访问主存，传送完一个数据字后立即释放总线，是一种单字传送方式，每个字传送完后 CPU 可以访问主存，选项C错误。停止 CPU访存法则是指在整个数据块的传送过程中，使 CPU脱离总线，停止访问主存。
- **第7章 第58题**：DMA 在预处理和后处理阶段需要 CPU 来处理，而数据传输阶段由 DMA 控制器完成。
- **第7章 第61题**：DMA（直接内存访问）适用于高速、大块数据传输的设备，因其可在不占用 CPU 情况下直接与内存交换数据。网卡和固态硬盘均属于高带宽的块设备，适合采用 DMA方式。而键盘和针式打印机是典型的低速字符设备，采用中断或程序查询方式通常更高效。
