## 三、知识点要点（摘自本书解析）

- **第3章 第93题**：Cache为2路组相联，组号=块号 mod2，组内采用LRU算法。对20 次主存块访问序列模拟，缺失发生在第1、2、4、6、11、17、19、20次，共8次。缺失率=8/20=40%。
- **第3章 第95题**：当K=1时，每组仅含1块，主存块只能映射到唯一Cache 位置，属于直接映射，选项A 正确，选项B错误。当K=M时所有块组成一组，即全相联映射，选项C错误。若Cache共M块、每组K块，则组数为 M/K，应称为K路组相联，而非“M/K路”，故选项D错误。
- **第3章 第98题**：块大小为16B，所以块内地址字段为4位；Cache 容量为128KB，采用8路组相联，共有128KB-（16Bx 8）=1024组，组号字段为10位：剩下为标记字段。1234567H 转换为二进制数 00010010 0011 0100 01010110 0111，标记字段对应高14位，即048DH。
- **第3章 第102题**：组相联映射的主存地址结构为：标记+ Cache 组号+块内地址。Cache 块大小增加一倍，则字块内地址的位数增加1位。Cache 组数=（Cache 总容量/Cache块大小）m，所以 Cache 组数减少一半；Cache 组号 = 主存块号 MOD Cache 组数，所以 Cache组号也减少1位。主存总容量不变，则主存地址总长度不变，字块内地址和 Cache组号一个增1位，一个减1位，因此标

- **第3章 第104题**：主存块大小为1个字，即32位，按字节编址，所以块内地址占2位。在全相联映射方式下，主存地址只有两个字段，所以标志占32-2=30位。因为采用回写法，所以需1位修改位：因为采用随机替换算法，所以无须替换控制位。每个 Cache 行总位数为 32bit（数据位）+ 30bit（标记位）+ Ibit（修改位）+ Ibit（有效位）=64bit。综上，Cache 总容量至少应有 32Kx64bit= 20
- **第3章 第105题**：主存块大小为32 字节，按字节编址，所以块内地址占5位。采用4路组相联映射方式，共64行，分64/4=16组，所以组号占4位。因为2593=0•0101 000100001，根据主存地址划分的结果，可以看出第2593号存储单元所在主存块Cache组号为 0001。
- **第3章 第108题**：对于直接映射，主存中的每一块只能装入 Cache 中的唯一位置，若产生块冲突，原来昀块将被无条件换出，因此无须考虑替换问题，而组相联映射和全相联映射都需要考虑替换问题。先进先出算法需要对每个 Cache 行打一个时间截，记录何时装入了一个新主存块。
