## 三、知识点要点（摘自本书解析）

- **第1章 第37题**：说法I错误：通用操作系统使用时间片轮转调度算法，用户运行程序并不需要预先预订运行时间。说法II正确：操作系统执行程序时，必须从起始地址开始执行。说法I错误：编译器是操作系统的上层软件，不是操作系统需要提供的功能。说法IV正确：操作系统是计算机资源的管理者，管理计算机系统资源是操作系统关心钓主要问题。
- **第1章 第44题**：说法I错误：批处理的主要缺点是缺少交互性。批处理系统的主要缺点是常考点，读者对此要非常敏感。说法I正确：输入/输出指令属于特权指令，只能由操作系统使用，因此必须在内核态下执行。说法亚错误：多道性是为了提高系统利用率和吞吐量而提出的。说法IV正确：1/O通道实际上是一种特殊的处理器，它具有执行1/O指令的能力，并通过执行通道程序来控制IO操作。
- **第1章 第49题**：CPU通过程序状态字寄存器中的某个位来标志当前的状态，但是修改程序状态字指令本身就属于特权指令，不能在用户态下执行。当 CPU 执行到一条访管指令或陷阱指令时，会引起访管中断或陷阱中断，CPU 会保存断点和其他上下文环境，然后切换到内核态。也就是说，从用户态转换到内核态，不是通过指令来修改CPU 的状态标志位，而是由 CPU 在中断时自动完成。中断处理程序一般在内核态执行，因此无法完成“转换成内核
- **第1章 第50题**：直接管理系统资源指令（如设置时钟、启动/关闭硬件设备、切换进程、设置中断等）、系统状态修改指令（如修改中断向量表、切换 CPU 飽运行模式等）、系统控制指令（如停机指令、重启指令等），都属于特权指令，必须在内核态执行。普通的数据处理指令、流程控制指令、读操作指令都不会影响系统的安全和整体状态，可以在用户态执行。
- **第1章 第51题**：用户程序通过陷入指令让 CPU 模式从用户态转入内核态，因此在用户态执行。虽然调用发生可能在用户态（注意区分调用和执行），但是系统调用指令必然在内核态执行。开中断指令和关中断指令都属于特权指令，能够影响到系统的运行，必须在内核态执行。无论是分支跳转指令还是无条件转移指令，都属于普通的程序流程控制指令，在用户态执行。中断屏蔽字寄存器属于中断控制器一部分，而中断控制器是属于1/O 接口的，因此设置中断
- **第1章 第52题**：磁盘调度程序控制磁头的运行，和硬件密切相关，运行在内核态。中断处理程序在中断发生后由操作系统内核调用，运行在内核态。设备驱动程序用于和硬件设备进行通信，运行在内核态。操作系统初始化程序负责初始化系统资源、设置环境、加载驱动程序等，运行在内核态。
- **第1章 第59题**：本题关键是对“在用户态发生”（注意与“在用户态执行”区分）的理解。对于选项 A，系统调用是操作系统提供给用户程序的接口，系统调用发生在用户态，被调用程序在内核态下执行。对于选项B，外中断是用户态到内核态的“门”，也发生在用户态，在内核态完成中断处理过程。对于选项C，进程切换属于系统调用执行过程中的事件，只能发生在内核态；对于选项D，缺页产生后，在用户态发生缺页中断，然后进入内核态执行缺页中断服务程
- **第1章 第61题**：整数除以零是非法操作，因此CPU 会检测到异常，并切换到内核态进行异常处理。sin（）函数是C语言中的普通运算类库函数，且不会引发系统调用，在用户态执行。在用户态触发 read 系统调用时，会通过 Trap 指令陷入内核态，由 CPU 执行相应系统调用服务例程。
