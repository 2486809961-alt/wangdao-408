## 三、知识点要点（摘自本书解析）

- **第6章 第56题**：DNS 采用 UDP来传送数据，UDP是一种面向无连接的协议。
- **第6章 第58题**：HTTP 在传输层使用TCP，端口号为80。TCP25号端口是为 SMTP保留的。
- **第6章 第59题**：因为不知道服务器的IP 地址，所以先要用 DNS进行域名解析，然后使用 HTTP进行客户和服务器之间交互。需要用到的传输层协议是 UDP（DNS使用）和TCP（HTTP使用）。
- **第6章 第60题**：统一资源定位符负责标识万维网上的各种文档，并使每个文档在整个万维网范围内具有唯一的标识符 URL。
- **第6章 第61题**：HTTP 在传输层用的是TCP。HTTP/1.0只支持非持续连接，所以每请求一个对象需要建立一次TCP 连接，传输1个基本 html对象和3个gif对象，共需建立4次TCP连接。
- **第6章 第65题**：非持续连接对每次请求/响应都建立一次TCP 连接。在浏览器请求一个包含100 个图片对象的 Web页面时，服务器需要传输1个基本HTML文件和100个图片对象，因此共有101个对象，需要打开和关闭 TCP 连接101次。
- **第6章 第66题**：建立第一个 TCP 连接需要 1RTT，请求并接收 Web页需要 IRTT。浏览器支持并行 TCP连接，因此在收到 Web 页后可同时建立7个并行的 TCP 连接，以请求和接收7个小图像文件。因此，总往返时间 RTT数=IRTT（建立第一个TCP连接）+ IRTT（请求 Web页）+IRTT（建立7个并行 TCP连接）+1RTT（请求7个小图像文件）=4RTT。
- **第6章 第67题**：从发出 HTTP请求报文开始，所以此时 TCP连接已经建立。本题采用了流水线的持续连接。第1个RTT请求并收到html页面，收到 html页面后才能发送对其引用小图像的请求，所以第2个RTT 请求并收到3幅小图像，合计耗费2RTT。
- 其余 6 题的解析见各题目页。
