# 排版规范 · 408 题库

> 一套版式两种载体：**CSS 片段**（`408-排版.css`）+ **笔记结构**（HTML 段落 + Callout）。
> 全部 2923 题、26 章、15 大类、632 考点页都由同一套规则渲染。

## 设计原则

| 原则 | 落地 |
| --- | --- |
| 题干像试卷 | 题干用宋体、1.06em、行距 2.0，选项 A/B/C/D 自动两列网格 |
| 答案像批注 | 绿底胶囊，一眼扫到，不喧宾夺主 |
| 考点像标签 | 圆形 tag 流，不占正文宽度 |
| 页码可追溯 | 虚线胶囊：`题目 PDF p281 · 原书 p269` |
| 复盘可勾选 | 虚线框 + 复选框，不干扰阅读 |

## 组件表（CSS 类）

| 类名 | 用在哪 | 效果 |
| --- | --- | --- |
| `.wd-head` `.wd-badge` `.wd-chip` | 每篇题目首行 | 科目章号徽章 + 题型/小节/大类/真题年份胶囊 |

| `.wd-expl` | 解析要点 | 首段带「解」方标、两端对齐 |
| `.callout[data-callout="info"] ul` | 考点 | `flex` 标签流，胶囊描边 |
| `.callout[data-callout="example"] code` | 教材出处 | 虚线页码胶囊 |

## Editing Toolbar 配置

**位置**：顶栏；选中文字时自动浮出（`shouldShowMenuOnSelect: true`）。

15 个按钮，按复盘顺序排：

```
撤销 · 重做 │ 标题H1-H4 │ 加粗 · 斜体 · 高亮 · 删除线 │ 公式(行内/块/上标/下标)
│ 块(引用/Callout/分割线/代码块) │ 列表(任务/无序/有序/重排号) │ 表格 · 双链 · 外链
│ 清理(删空行/并成一行/压缩空格/全角半角/清格式) │ 专注
```

**4 个 408 专用一键命令**（拖动到工具条即可用）：

| 命令 | 用法 | 效果 |
| --- | --- | --- |
| 题干卡 | 选中一段 OCR 题干 | 包成 `> [!question] 题干` |
| 选项网格 | 选中 `A. …` 到 `D. …` 四行 | 每行变 `<div class="wd-opt"><b>A</b><span>…</span></div>` |
| 答案牌 | 光标停在 `B` 这类单独字母行 | 变 `<span class="wd-ans">B</span>` |
| 页码章 | 选中「281 页」这类文字 | 变 `<span class="wd-page">p281</span>` |

## 手工维护一篇题的标准动作

1. 打开 `Ⅲ 数据结构/第07章 查找/7.2 顺序查找和折半查找/考点名/第7章 第XX题.md`，题干框内粘贴 OCR 原文。
2. 选中选项四行 → 工具条「选项网格」。
3. 答案行 → 「答案牌」。
4. 出处行 → 「页码章」。
5. `Ctrl/Cmd + P` → `Toggle reading view` 看排版成品。

## 已知边界

- **Callout 内不能放裸 HTML**：Obsidian 会把 callout 里的 `<div>` 吞成空壳（实测），所以答案/考点/页码改用原生 Markdown（加粗、列表、行内代码）+ CSS 改造；只有选项网格放在 callout 外面。
- 选项网格两列在窗口 < 900px 时自动变一列。
- 打印（`Cmd+P`）已隐藏工具栏、去掉行宽限制、避免卡片跨页断开。
