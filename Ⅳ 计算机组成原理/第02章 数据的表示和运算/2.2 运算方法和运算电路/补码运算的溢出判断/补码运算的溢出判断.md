## 三、知识点要点（摘自本书解析）

- **第2章 第39题**：该数是一个正数（最高位为 0），按照补码算术移位规则，算术左移两位后，移出了最高位 01，低位补0，因此算术左移两位后结果是01010100。虽然移位后该数的符号位仍为0，但是移出了有效位1，所以本次算术移位发生了溢出。
- **第2章 第40题**：80H=（100000 0 0）＜<1＝00000000，左移前符号位为 1，左移后的符号位为0，溢出。90H=（100100 0 0）＜<1=00100000，左移前的符号位为1，左移后的符号位为0，溢出。BOH=（101100 0 0）＜<1=01100000，左移前的符号位为1，左移后的符号位为0，溢出。COH=（1100 00 0 0）＜<1=10000000，左移前的符号位为1，左移后的
- **第2章 第41题**：该数是一个负数（最高位为 1），按照算术补码移位规则，负数右移添1，负数左移添0，所以10010101右移一位后值为 1100 1010。
- **第2章 第43题**：算术左移时，低位补0；算术右移时，高位补符号位。BAH=（1011 10 1 0）z，算术左移1位得（011101 0 0）z=74H，左移前后的符号位不同，溢出：算术右移1位得（110111 0 1）2=DDH。
- **第2章 第44题**：三种溢出判别方法，均须有溢出判别电路，可用“异或”门来实现。
- **第2章 第45题**：机器运算发生溢出的根本原因是计算机的字长有限，所以不能表示超过一定范围的数据。
- **第2章 第46题**：首先将r和rz转换为真值，FSH=11110101，转换为原码是1000 1011，真值为-11; EEH =1110 1110，转换为原码是1001 0010，真值为-18，8位补码表示范围为［-128,127］，rixrz哟结果为198，超出了8位补码的表示范围，发生溢出。
- **第2章 第47题**：模4补码具有模2补码的全部优点且更易检查加减运算中溢出问题，选项 A错误。需要注意的是，存储模4补码仅需一个符号位，因为任何一个正确的数值，模4补码的两个符号位总是相同，选项B正确。只在把两个模4补码数送往 ALU 完成加减运算时，才把每个数时符号位的值同时送到 ALU 的双符号位中，即只在 ALU 中采用双符号位，选项C、D错误。
- 其余 12 题的解析见各题目页。
