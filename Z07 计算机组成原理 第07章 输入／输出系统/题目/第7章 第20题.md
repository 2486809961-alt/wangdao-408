# 第7章 第20题

<div class="wd-head"><span class="wd-badge">计算机组成原理 · 第07章 · 20</span><span class="wd-chip qtype-选择">选择题</span><span class="wd-chip">7.3 I/O方式</span><span class="wd-chip">总线与 I/O</span></div>

> [!question] 题干
> 下列关于中断I/O方式叙述中，错误是（）。

<div class="wd-opts">
<div class="wd-opt"><b>A</b><span>CPU 对外部中断响应不可能发生在一条指令执行过程中</span></div>
<div class="wd-opt"><b>B</b><span>在中断1/0方式下，外设接口中寄存器和CPU 中的寄存器直接交换数据</span></div>
<div class="wd-opt"><b>C</b><span>中断请求是 CPU时间，要求CPU 执行程序来处理发生相关事件</span></div>
<div class="wd-opt"><b>D</b><span>只要有中断请求发生，一条指令执行结束后CPU 就进入中断响应周期</span></div>
</div>

> [!success] 答案
> **D**

## 解析要点

<div class="wd-expl">

CPU 总是在一条指令结束时检查外中断请求，因此对外中断的响应只可能发生在一条指令结束时。中断1/0方式下，CPU 执行中断服务程序时会执行相应 1/0指令，实现 CPU 的通用寄存器和外设接口中的寄存器之间的直接数据交换。中断请求就是要求 CPU 执行程序来处理发生的相关事件。选项D 在下列两种情况下错误：① 关中断时，CPU 检测不到中断请求，因此不会进入中断响应周期：② 当有中断请求请求源被中断屏蔽字屏蔽时，也不会进入中断响应周期。

</div>
