# 第7章 第46题

<div class="wd-head"><span class="wd-badge">计算机组成原理 · 第07章 · 46</span><span class="wd-chip qtype-选择">选择题</span><span class="wd-chip">7.3 I/O方式</span><span class="wd-chip">总线与 I/O</span><span class="wd-chip">真题 2013</span></div>

> [!question] 题干
> 【2013统考真题】下列关于中断1/O方式和DMA 方式比较的叙述中，错误的是（）。

<div class="wd-opts">
<div class="wd-opt"><b>A</b><span>中断1/0方式请求是CPU 处理时间，DMA 方式请求的是总线使用权</span></div>
<div class="wd-opt"><b>B</b><span>中断响应发生在一条指令执行结束后，DMA响应发生在一个总线事务完成后</span></div>
<div class="wd-opt"><b>C</b><span>中断1/O方式下数据传送通过软件完成，DMA 方式下数据传送由硬件完成</span></div>
<div class="wd-opt"><b>D</b><span>中断1/O方式适用于所有外部设备，DMA 方式仅适用于快速外部设备</span></div>
</div>

> [!success] 答案
> **D**

## 解析要点

<div class="wd-expl">

中断1/O方式：在I/O 设备输入每个数据的过程中，由于无须 CPU 干预，因此可使 CPU 与I/O 设备并行工作。仅当输完一个数据时，才需要 CPU 花费极短的时间去做一些中断处理。因此中断申请使用是 CPU 处理时间，发生时间是在一条指令执行结束之后，数据在软件的控制下完成传送。而 DMA方式与之不同。DMA 方式：数据传输的基本单位是数据块，即在 CPU 与1O设备之间，每次传送至少一个数据块；DMA 方式每次申请的是总线的使用权，所传送的数据是从设备直接送入内存的，或者相反；仅在传送一个或多个数据块的开始和结束时，才需要 CPU 干预，整块数据的传送是在控制器的控制下完成的。中断 1/O 方式不适合高速外设；多路型 DMA控制器也适合同时为多个慢速外设服务，选项D错误。

</div>
