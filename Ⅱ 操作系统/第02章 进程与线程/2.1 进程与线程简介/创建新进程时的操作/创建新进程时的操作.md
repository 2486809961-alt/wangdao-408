## 三、知识点要点（摘自本书解析）

- **第2章 第11题**：并发进程执行相对速度与进程调度策略有关，因为进程调度策略决定了哪些进程可以获得处理机，以及获得处理机的时间长短，从而影响进程执行的速度和效率。
- **第2章 第12题**：进程创建原语的执行过程：申请空白PCB，并为新进程申请唯一的数字标识符。为新进程分配资源，包括内存、I/0 设备等。初始化 PCB，将新进程插入就绪队列。从上述过程可以看出，为进程分配 CPU 不是由进程创建原语完成的，而是由进程调度实现的。
- **第2章 第14题**：用户登录时，操作系统会为用户创建一个登录进程，用于验证用户身份和提供用户界面。高级调度即作业调度，会从后备队列上选择一个作业调入内存，并为之创建相应进程。操作系统响应用户提出的请求时，通常会为用户创建一个子进程，用于执行用户指定的任务或程序。用户打开一个浏览器程序时，也是一种操作系统响应用户请求的情况，同样会创建一个新进程。
- **第2章 第25题**：虽然父进程创建了子进程，它们有一定的关系，但仍然是两个不同进程，拥有各自 PID，选项A错误。父进程和子进程是相互独立的，两个进程能并发执行，且互不影响，选项B正确，选项D错误。撤销一个进程并不一定会导致另一个进程也被撤销，父进程撤销后，子进程可能有两种状态：① 子进程一并被终止；② 子进程成为孤儿进程，被 init进程领养。子进程撤销不会导致父进程撤销，选项C错误。
- **第2章 第27题**：进程是程序的一次执行过程，它不仅包括程序的代码，还包括程序的数据和状态。同一个程序经过多次创建，运行在不同数据集上，会形成不同的进程，它们之间没有必然的联系。
- **第2章 第30题**：我们先要考虑创建进程的过程，当该进程所需的资源分配完成而只等 CPU 时，进程的状态为就绪态，因此所有就绪PCB一般以链表方式链成一个厚列，称为就绪队列。
- **第2章 第39题**：线程是进程内一个相对独立的执行单元，但不能脱离进程单独运行，只能在进程中运行。引入线程是为了减少程序执行时的时空开销。一个进程可包含一个或多个线程。
- **第2章 第51题**：进程创建原语完成的工作是：向系统申请一个空闲 PCB，为被创建进程分配必要的资源，然后将其PCB 初始化，并将此 PCB 插入就绪队列，最后返回一个进程标志号。当调度程序为进程分配 CPU后，进程开始运行。所以进程创建过程中不会包含分配 CPU 过程，这不是进程创建者的工作，而是调度程序的工作。
- 其余 3 题的解析见各题目页。
