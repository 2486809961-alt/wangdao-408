## 怎么读

- **大类网**是五级骨架：4 大类 → 26 章 → 131 节；节卡写着「N 考点 · M 题」，双击章卡进 00 本章复盘.md，双击节卡进 00 本节考点 · 节名.md。
- **各科知识网**再下一级：章 → 节 → 考点，考点卡带「年份 · 题数」，一眼看出哪年考过。
- **真题年份网**横向看一个考点扫过哪些年（轮回周期），纵向看一年里哪些考点扎堆（命题偏好）。

## 重新生成

画布由目录结构脚本生成（幂等，换书后重跑即可）：

~~~bash
cd /tmp && python3 wd408_v5d.py canvas5
~~~

落盘前脚本自查节点重叠，overlaps 必须为 0。

## 关系图谱过滤规则（全局图谱）

图谱只留五级骨架（大类 / 章 / 节 / 考点），题目与六类辅助目录不进图；文件本身全部保留在左侧目录树。

过滤式写在 .obsidian/graph.json 的 search 字段，图谱左上角可见、可随时改：

~~~text
-file:/第\d+章 第\d+题/ -path:"00 教材" -path:"00 索引" -path:"01 思维导图" -path:"02 章节笔记" -path:"图谱" -path:"真题"
~~~

| 排掉的 | 数量 | 为什么 |
| --- | --- | --- |
| 五级题目页 | 2923 | 题目只在目录树里刷，图谱里会把骨架糊成一团 |
| 00 教材 / 00 索引 / 01 思维导图 / 02 章节笔记 / 图谱 / 真题 | 32 篇 | 元数据与素材层，不属于知识结构 |
