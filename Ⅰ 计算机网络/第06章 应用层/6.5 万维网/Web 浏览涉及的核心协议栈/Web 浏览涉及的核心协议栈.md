## 三、知识点要点（摘自本书解析）

- **第6章 第57题**：建立浏览器与服务器之间的连接需要知道服务器的 IP 地址和端口号（80端口是熟知端口），而访问站点时浏览器从用户那里得到是 WWW 站点的域名，所以浏览器必须首先向 DNS 请求域名解析，获得服务器的 IP地址后，才能请求建立 TCP连接。
- **第6章 第71题**：接入网络时可能会用到 PPP，选项 A可能用到；计算机不知道某主机的 MAC地址时，用IP地址查询相应 MAC地址会用到 ARP，选项B可能用到；访问 Web 网站时，若 DNS 缓冲没有存储相应域名IP地址，用域名查询相应钓 IP地址时要使用DNS，而DNS是基于 UDP哟，所以选项C可能用到；SMTP只有使用邮件客户端发送邮件，或邮件服务器向其他邮件服务器发送邮件时才会用到，单纯地访问 Web
- **第6章 第75题**：1） 应用层。HTTP:WWW 访问协议；DNS：域名解析服务。 2） 传输层。TCP：HTTP提供可靠的数据传输；UDP：DNS 使用 UDP传输。 3） 网络层。IP:IP 包传输和路由选择；ICMP：提供网络传输中的差错检测；ARP：将本机的默认网关IP地址映射成物理MAC地址。
- **第6章 第77题**：1） 以太网帧的数据部分是 IP数据报，只要数出相应字段所在的字节即可。由图3可知以太网帧首部有6+6+2=14B，由图4可知 IP数据报首部目的IP地址字段前有4x4=16B，从图2的帧第1字节开始数14+16=30B，得到目 IP 地址为 40.aa.62.20（十六进制数），转换成十进制数为64.170.98.32。由图2可知以太网帧前6字节 00-21-27-21-51-ee 是日钓MAC
