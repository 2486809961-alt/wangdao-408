## 三、知识点要点（摘自本书解析）

- **第6章 第56题**：DNS 采用 UDP来传送数据，UDP是一种面向无连接的协议。
- **第6章 第57题**：建立浏览器与服务器之间的连接需要知道服务器的 IP 地址和端口号（80端口是熟知端口），而访问站点时浏览器从用户那里得到是 WWW 站点的域名，所以浏览器必须首先向 DNS 请求域名解析，获得服务器的 IP地址后，才能请求建立 TCP连接。
- **第6章 第58题**：HTTP 在传输层使用TCP，端口号为80。TCP25号端口是为 SMTP保留的。
- **第6章 第59题**：因为不知道服务器的IP 地址，所以先要用 DNS进行域名解析，然后使用 HTTP进行客户和服务器之间交互。需要用到的传输层协议是 UDP（DNS使用）和TCP（HTTP使用）。
- **第6章 第62题**：使用 HEAD方法时服务器可对 HTTP 报文进行响应，但不会返回请求对象，其作用主要是调试。另外三个选项中的方法的作用请查看本章中的表6.1。
- **第6章 第63题**：可以在HTTP中使用 Cookie 保存 HTTP服务器和客户之间传递的状态信息。
- **第6章 第66题**：建立第一个 TCP 连接需要 1RTT，请求并接收 Web页需要 IRTT。浏览器支持并行 TCP连接，因此在收到 Web 页后可同时建立7个并行的 TCP 连接，以请求和接收7个小图像文件。因此，总往返时间 RTT数=IRTT（建立第一个TCP连接）+ IRTT（请求 Web页）+IRTT（建立7个并行 TCP连接）+1RTT（请求7个小图像文件）=4RTT。
- **第6章 第71题**：接入网络时可能会用到 PPP，选项 A可能用到；计算机不知道某主机的 MAC地址时，用IP地址查询相应 MAC地址会用到 ARP，选项B可能用到；访问 Web 网站时，若 DNS 缓冲没有存储相应域名IP地址，用域名查询相应钓 IP地址时要使用DNS，而DNS是基于 UDP哟，所以选项C可能用到；SMTP只有使用邮件客户端发送邮件，或邮件服务器向其他邮件服务器发送邮件时才会用到，单纯地访问 Web
- 其余 2 题的解析见各题目页。
