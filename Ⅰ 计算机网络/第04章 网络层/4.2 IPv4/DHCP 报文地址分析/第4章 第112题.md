## 解析要点

<div class="wd-expl">

1） H2和H3与 Web 服务器处于不同的局域网，路由器R2、R3具有 NAT功能。当R2从WAN口收到来自 H2或H3发来的 HTTP请求时，根据 NAT 表发送给 Web 服务器的对应端口。为便外部主机能正常访问 Web 服务器，应在R2的NAT 表中增加一项，外网的IP地址配置为路由器外端IP 地址，内网的 IP地址配置为Web 服务器IP地址，HTTP的服务器端默认端口号为 80，因此外网和内网的端口号都需配置为 80。只需在R2中配置 Web服务器的 NAT表项，而不用在R3中配置 H2和H3NAT表项，原因在于 H2和H3是主动访问 Web 服务器，若不提前配置好 Web 服务器的NAT映射，则当 IP 分组到达R2时，就不知道应当把目IP 地址转换成专用网中的哪个本地IP地址。而R3会自动记录 H2和H3所对应IP地址和端口号，且客户端的端口号是随机分配，无法做静态配置，只能通过自动动态配置实现。R2的 NAT表配置如下：外网内网IP地址203.10.2.2端口号IP地址端口号192.168.1.

2

2） 因为启用了 NAT 服务，H2发送的P的源IP 地址应该是H2的内网地址，目的地址应该是R2外网IP地址，源IP地址是192.168.1.2，目IP 地址是203.10.2.2。R3转发后，将P的源IP地址改为R3的外网IP地址，目IP地址仍然不变，源IP地址是203.10.2.6，目的IP地址是203.10.2.2。R2转发后，将P目IP地址改为Web服务器的内网地址，源地址仍然不变，源IP地址是203.10.2.6，目IP地址是192.168.1.2。

</div>
